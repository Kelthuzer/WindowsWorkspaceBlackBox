# Проверка на Windows — 0.1.0

Статус: не выполнена в интерактивном Windows-сеансе разработчика. Это план приёмки, а не отчёт об успешно пройденных проверках.

1. Установить EXE. Проверить Program Files, ярлык, трей и запись автозапуска текущего пользователя. Процесс работает без повышения прав.
2. Открыть 5–10 программ, включая MPC, и 10 разных папок. Среди папок: UNC, пробелы, кириллица, корень диска, одинаковая папка в двух окнах.
3. В Windows 11 создать несколько вкладок, включая неактивные. Сохранить снимок. Сверить **все реальные пути** в JSON, а не только количество. Если появляется ошибка покрытия, сохранить журнал и номер сборки Windows — поддержка этой конфигурации не принята.
4. Разложить окна по двум мониторам; одно свернуть, другое развернуть. Сделать ручной снимок, убедиться в новом JSON, следующем автосохранении через пять минут и отсутствии снимка по старому расписанию.
5. Перезагрузить Windows в режиме Auto. До конца восстановления нового рабочего снимка не должно быть. Проверить папки, размеры, состояние и мониторы. MPC проверить отдельно: файл и позиция зависят от его собственных настроек.
6. Повторить в Manual. Ни одна программа не открывается автоматически. Через пять минут новые снимки допустимы, но «Восстановить последний» должен брать защищённый снимок до перезапуска.
7. Отсоединить дополнительный монитор и восстановить снимок: окна должны оставаться в рабочей области доступного монитора. Повторить с разным DPI.
8. Временно отключить доступ к UNC. Трей должен отвечать, локальные папки открываться, сетевой путь повторяться и при неудаче оставаться в исходном защищённом снимке.
9. Создать незавершённый JSON в snapshots: он должен пропускаться. Не редактировать единственный рабочий снимок.
10. Повторить восстановление в уже восстановленной сессии: лишние экземпляры приложений/папок не должны появляться. Проверить два документа одной программы и записать ограничения её восстановления.
11. Проверить отмену восстановления, выход во время сбора, повторный запуск EXE, блокировку/разблокировку сеанса.
12. Удалить программу. Файлы программы/ярлык/автозапуск удаляются, снимки остаются. Для удаления под другой административной учётной записью отдельно проверить HKCU исходного пользователя.

В отчёт включать версию Windows (`winver`), число мониторов и их масштаб, приложения, ожидаемые/фактические папки, соответствующий журнал. Командные строки и личные пути перед передачей журнала/JSON можно удалить.
